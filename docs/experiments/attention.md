# Quiet TV attention - design only

Secondary to customized Home. Prefer a silent native Codex needs you notice;
no arbitrary native-toast API is demonstrated. Pairing-success notice, native
Chromecast connection notice and DashCast's own Loading bar are different leads.
Default Cast title display took over the screen and is not an acceptable quiet
notification. An in-page notice is visible only while our page is open.

Proposed shared Mist App/Console control: OFF by default, target, critical-only
or decisions/completions, manual movie mode, optional timezone-aware schedule.
Both surfaces would use one settings authority; no write controls added to the
existing read-only TV client. Movie mode/schedule veto all automatic presentation.
Deduplicate, batch, rate-limit and expire resolved/stale events; enabling must not
replay backlog. Full Console takeover is a separate explicit opt-in, never fallback.

Measure before building: power/input/app reads are not verified playback detection.
The source-backed /state_extended lead requires a bounded approved correlation
test across native apps/HDMI; no polling or auto-launch enabled. No wake/input
switch, new outside access, TV setting or firmware change implied.
