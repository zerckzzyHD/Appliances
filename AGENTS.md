# Appliances instructions

This private repository contains two independent workbenches. Read the relevant
child AGENTS.md before work. Do not merge TV and bulb plans into another queue.

Preserve imported evidence and dated history byte for byte. Keep secrets, raw
private captures, settings, runtime state and dependencies out of Git. Do not
operate devices, restart Console, install tooling or change runtime settings
without the owner's exact authorization. No automatic cleanup or restoration.

Run the child gates and the root asset check documented in README.md. Stage
explicit paths only. In owner-directed SOLO work, a push requires the owner's
explicit authorization for that change: inspect the staged manifest, pass gates,
commit locally, push main without force and compare HEAD with `git ls-remote`.
Verify repository visibility rather than inferring it. DISPATCHED work never
pushes. Public publication or deployment needs separate exact approval.

Use the existing TV model workflow when relevant. Advisory consultation grants
no device, configuration or publication authority.
